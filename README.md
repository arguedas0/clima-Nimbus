- ## 📖 Sobre o projeto

**O quê:** uma aplicação web que mostra o clima de qualquer cidade a partir do nome digitado.

**Por quê:** vai ser primeiro projeto em JavaScript, criado para praticar consumo de APIs, manipulação do DOM e tratamento de erros, colocando em prática o que aprendi de HTML e CSS.

**Como:** o app usa a API gratuita [Open-Meteo](https://open-meteo.com/) (sem chave de API), busca as coordenadas da cidade e, com elas, consulta a previsão do tempo.

## ✨ Funcionalidades

- 🔍 Busca por nome de qualquer cidade
- 🌡️ Temperatura, sensação térmica, umidade e vento
- 📅 Previsão dos próximos dias (máxima e mínima)
- ⚠️ Mensagens claras para cidade não encontrada ou falha de conexão
- ⏳ Indicador de carregamento
- 📱 Layout responsivo
